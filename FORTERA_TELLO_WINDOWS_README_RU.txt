FORTERA TELLO BRIDGE — УСТАНОВКА ДЛЯ WINDOWS 10/11 x64

Эта сборка синхронизирована с исходниками опубликованного проекта Fortera в Lovable:
commit ec8412a2ef9574342ba5cd993516f3ffc7c1d791.

ЧТО УСТАНАВЛИВАЕТСЯ
- Локальный Windows-мост Fortera для обычного DJI/Ryze Tello.
- Отдельный Python 3.13.17 в профиле текущего пользователя (не меняет системный Python).
- Библиотеки WebSocket, NumPy и OpenCV.
- Окно Fortera Tello Bridge для запуска, остановки и настройки.
- WebSocket: ws://127.0.0.1:8765
- Реальное видео с камеры: http://127.0.0.1:8766/video
- JPEG для AI-наблюдения: http://127.0.0.1:8766/frame.jpg

УСТАНОВКА
1. Скачай ZIP этой ветки GitHub и распакуй его целиком в отдельную папку.
2. Дважды нажми INSTALL_FORTERA_TELLO.bat в корне распакованной папки.
3. Инсталлятор скачает Python с python.org, установит зависимости и создаст ярлык на рабочем столе.
4. Откроется окно Fortera Tello Bridge.

ПЕРВЫЙ ЗАПУСК
1. В поле Published Fortera website origin вставь только домен опубликованного сайта, например:
   https://my-fortera-site.lovable.app
   Не добавляй /live, слеш после домена, query-параметры или другие пути.
   Важно: введи точный адрес, который виден в адресной строке браузера при открытом опубликованном Fortera.
2. Нажми Check Tello Wi-Fi. Если компьютер подключён к Wi-Fi Tello, SDK должен ответить OK.
3. Нажми START BRIDGE.
4. Нажми Copy token.
5. Открой опубликованный Fortera → Live Drone.
6. Bridge URL: ws://127.0.0.1:8765
   Pairing token: вставь скопированный токен.
7. Нажми Connect / Check bridge. После подключения Live Drone должен показать реальный видеопоток Tello и телеметрию.

СЕТЬ
- Wi-Fi компьютера подключается непосредственно к сети TELLO-XXXXXX.
- Сам Tello не подключается к домашнему роутеру.
- Чтобы сайт и Gemini имели Интернет, оставь Интернет на Ethernet или используй второй Wi-Fi адаптер.
- Окно моста и браузер должны работать на одном компьютере: 127.0.0.1 — это локальный адрес этого компьютера.
- Используй Chrome или Edge и разреши доступ сайта к локальной сети, если браузер спросит.

ПРОФИЛЬ И БЕЗОПАСНОСТЬ
- По умолчанию включён Indoor Demo.
- Высота взлёта: штатная высота Tello около 1 м, программный лимит 1.2 м.
- Один шаг: 0.2–0.5 м по одной оси, поворот до 45°, скорость 20 см/с, радиус от расчётной точки старта 2 м.
- Минимум батареи: 50% для взлёта, 40% для движения.
- Камера анализируется локально для проверки свежести, чёрного/замороженного видео, текстуры и оптического потока.
- Эти проверки являются предупреждениями, а НЕ датчиком глубины и НЕ обходом препятствий. Gemini-наблюдения тоже не разрешают движение.
- Обычный Tello не имеет GPS и передних датчиков обхода препятствий. Не летай через двери, окна, узкие проходы или рядом с людьми. Не используй автоматический выход наружу.
- Модель Tello EDU и Mission Pads здесь выключены; эта сборка рассчитана на обычный Tello.

ОСТАНОВКА
Сначала посади дрон через Fortera Live Drone и убедись, что он стоит на полу. Затем нажми STOP BRIDGE в окне программы. Команда остановки закрывает контроллерский сеанс и запрашивает HOLD; она не заменяет посадку.

ОГРАНИЧЕНИЕ ПРОВЕРКИ
Lovable сообщил о 106 автоматических тестах моста и 260 тестах приложения, проверенных на fake Tello/синтетическом видео. Это не испытания реального самолёта. Перед полётом требуется отдельная проверка на физическом Tello: SDK, видео, STOP, телеметрия, задержка и поведение при потере соединения. Не считай систему сертифицированной для автономной навигации.
